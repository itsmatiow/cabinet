# Cabinet

**Cabinet** is a modern hotel management dashboard built to manage bookings, cabins, guests, and daily hotel operations through a clean and responsive interface.

The project focuses on providing an intuitive dashboard experience with efficient data management, interactive charts, authentication, and responsive layouts across different screen sizes.

##✨ **Features**

* Hotel management dashboard
* Booking management
* Cabin management
* Guest information management
* Check-in and check-out functionality
* Booking status management
* Dashboard statistics
* Sales and stay duration charts
* Search, filtering, and sorting
* User authentication
* Protected routes
* Dark mode
* Responsive design
* Form validation
* Error handling
* Data caching and synchronization

🚀 **Getting Started**

1. Clone the repository

```bash
git clone https://github.com/itsmatiow/cabinet.git
```

2. Navigate to the project

```bash
cd cabinet
```

3. Install dependencies

```bash
npm install
```

4. Create environment variables

Create a `.env` file in the project root:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_KEY=your_supabase_key
```

5. Start the development server

```bash
npm run dev
```

The project will be available at the local development URL provided by Vite.
